# Gueule de Vigneron

Site vitrine et marchand pour un negociant en vin.

## Positionnement

Gueule de Vigneron met en avant la rencontre entre les personnes, les domaines et les sensations. Le site devra servir a la fois:

- les particuliers qui cherchent des bouteilles, des coffrets et des experiences;
- les entreprises qui organisent des degustations ou des formations;
- les restaurateurs qui souhaitent construire et suivre leur carte des vins;
- le Club Epicure et ses trois niveaux de decouverte.

## Perimetre prevu

- site vitrine avec presentation de l'histoire, de l'approche et des domaines partenaires;
- boutique en ligne pour les bouteilles, coffrets et offres sur mesure;
- degustations privees, evenements et formations;
- espace professionnel protege;
- catalogue evolutif d'environ 350 references;
- contenus et points d'entree adaptes aux clients particuliers et professionnels.

## Methode de travail

Les pages et leurs fonctionnalites seront precisees progressivement dans `Spec.txt`, page par page, avant de choisir l'architecture technique finale.

## Demarrage

Le projet est initialise localement avec Git. La creation du depot distant GitHub pourra etre faite avec:

```powershell
git remote add origin https://github.com/<compte>/GueuleDeVigneron.git
git push -u origin main
```

## Notes

Le site devra respecter la reglementation applicable a la vente d'alcool, notamment les controles d'age, les mentions legales, la protection des donnees et les conditions de livraison.
